## 模块目标

项目排期模块要帮助管理层快速判断：

- 每个月每个里程碑要完成哪些项目
- 项目当前是正常、延期风险、必然延期、已完成还是延期完成
- 规划视图和预测视图之间有什么差异
- 哪些项目有异常或需要管理层关注
- 项目上线月份是否符合年度规划

上线日历模块要帮助管理层按年度查看项目上线节奏，并支持后续通过拖拽项目调整规划。

## 数据来源口径

项目基础信息来自 `Project` 表，导入自真实测算 JSON 的 `projects`。

关键字段：

- `projectName`：项目名称
- `plannedLaunchDate`：项目信息表中的计划上线 / 预估出货日期
- `projectTeamId`：项目组
- `projectOwnerId`：产品研发
- `artOwnerId`：产品研发美术
- `modelingOwnerId`：项目级建模负责人
- `routeType`：路线
- `status` / `currentStage`：项目状态

测算结果来自：

- `ScheduleProjectResult`
- `ScheduleTaskResult`

关键字段：

- `plannedLaunchDate`：测算中的计划上线日期
- `forecastLaunchDate`：预测 / 实际完成后的上线日期
- `delayDays`：上线延期天数
- `projectProgressPercent`：项目整体进度
- `riskLevel`：测算风险
- `rawResult`：原始测算结果

## 里程碑映射

已确认的任务编号到里程碑映射：

```text
原画里程碑：任务 1-6
建模里程碑：任务 7-10
红蜡里程碑：任务 11-15、17、18
产前里程碑：任务 21-27
大货里程碑：任务 30
平面里程碑：其他平面设计相关任务
```

注意：平面里程碑不是兜底杂项，而是平面设计相关任务，只是任务跨度较大。

## 视图口径

### 规划视图

按计划完成月份显示项目里程碑。

用途：

- 看原本计划每个月应该完成什么
- 判断规划分布是否均衡

### 预测视图

未完成任务看预测完成月份。

已完成任务看实际完成月份。

用途：

- 看真实推进后，里程碑实际上落在哪个月
- 已完成里程碑不能因为旧计划或错误预测飘到不合理月份

### 上线日历

按项目信息表中的 `plannedLaunchDate` 归月。

用途：

- 看年度规划中每个月应上线哪些项目
- 后续通过拖拽项目调整上线规划

上线日历每个年度从春节后的第一个月开始，到下一个春节前，共 12 个月。

当前已实现年度切换。例如：

- `26年度`：26年3月 - 27年2月
- `27年度`：27年3月 - 28年2月

## 状态口径

当前统一状态：

```text
已完成：绿色
延期完成：深绿色
正常推进：白色
延期风险：黄色
必然延期：红色
```

重要规则：

- 已完成项目不再显示为黄色或红色
- 已完成但晚于计划，显示为 `延期完成`
- 黄色和红色只用于未完成且仍需要处理的延期风险
- `只看风险` 应只关注 `延期风险` 与 `必然延期`
- `延期完成` 是历史结果，不是当前待处理风险

## 小鸟4代基准样本

小鸟4代是当前校准状态口径的关键测试项目。

已确认事实：

```text
项目：小鸟4代
计划上线：2026-04-25
实际完成：2026-05-08
延期天数：8 天
项目状态：已完结
页面状态：延期完成
```

页面应表现为：

- 上线日历：位于 `26年4月`，深绿色卡片，显示计划 2026-04-25、完成 2026-05-08、晚 8 天
- 项目详情：显示“计划上线 2026-04-25”“实际完成 2026-05-08”
- 风险文案：`小鸟4代 已于 2026-05-08 完成，较计划上线 2026-04-25 晚 8 天。`
- 里程碑规划视图：按计划月份显示
- 里程碑预测视图：已完成里程碑按实际完成月份显示
- 不应显示为红色必然延期

当前小鸟4代里程碑结果：

```text
原画里程碑：规划 25年8月，预测/实际 25年8月，已完成
建模里程碑：规划 25年10月，预测/实际 25年8月，已完成
红蜡里程碑：规划 25年12月，预测/实际 25年11月，已完成
产前里程碑：规划 26年3月，预测/实际 26年4月，延期完成
平面里程碑：规划 26年4月，预测/实际 26年4月，已完成
大货里程碑：规划 26年4月，预测/实际 26年5月，延期完成
```

## 当前已实现功能

规划视图：

- 里程碑看板（规划）按计划月份显示
- 上线日历按项目计划上线日期归月
- 表格视图按上线计划显示项目清单，支持新增项目、删除项目、编辑计划上线 / 路线 / 项目组 / 建模负责人，并可导出为 Excel 可打开的 CSV
- 任务明细独立显示最新一次测算生成的全部任务明细，字段对齐旧版 `项目后续任务测算-v5.xlsx` 的任务表口径
- 项目录入视图作为项目规划录入入口，当前为前端表单入口，保存接口待继续完善

压力预测：

- 月份纵向滚动
- 六个里程碑横向列
- 使用原预测视图口径
- 支持搜索项目
- 支持只看风险
- 已完结项目也显示
- 初始定位会从最早未完成的历史月份或当前月份开始
- 可以继续向上滚动查看更早月份

上线日历：

- 按年度周期显示 12 个月
- 支持年度切换
- 按项目计划上线日期归月
- 规划卡显示项目名称、可编辑计划上线日期、预测上线时间、项目组、建模负责人
- 支持拖拽卡片形成规划草稿
- 支持拖拽到日历滚动区域上下边缘时自动滚动，便于跨月份移动项目
- 支持直接编辑计划上线日期形成规划草稿
- 支持保存规划草稿，按具体日期写回 `Project.plannedLaunchDate`，生成 `ScheduleAdjustment` 和 `TaskDragLog`
- 保存后会自动触发重新测算

项目详情：

- 项目基本信息
- 当前任务
- 计划上线
- 实际完成 / 预测上线
- 项目进度
- 建模进度
- 风险提示
- 本周需要处理
