## 业务口径

建模里程碑 = `ScheduleTaskResult.taskNo` 在 `7, 8, 9, 10` 的任务聚合到项目级。

当前页分组使用当前日期所在月份：

- 本月
- 之前未完成
- 下月

项目已进入红蜡、模具、大货、已完结时，建模里程碑视为已完成，避免历史项目误报逾期。

超载规则：

```text
建模师排队款式数 > 4
```

未更新提醒：

```text
建模中 且 超过 3 天未更新
```

款式拖拽分配目前只做前端草稿，不持久化。
