# 项目排期模块边界说明

最后更新：2026-05-31

## 1. 核心原则

项目排期模块不主动向其他模块输出业务事件，也不直接修改其他模块数据。

项目排期只做四件事：

- 接收输入。
- 记录项目规划和任务事实。
- 接收并保存统一排期内核计算结果。
- 提供对外可读信息。

凡是预测上线、预测完成、延期判断、风险等级、里程碑状态等逻辑结论，只能来自统一排期内核结果。项目排期页面、导入逻辑、接口和组件都不能自己复制这些计算规则。

## 2. 输入

输入指外部或内核主动提交给项目排期的信息。项目排期收到输入后，可以创建或更新自己的项目规划数据、任务事实数据或排期结果数据。

项目排期输入分为三类。

### 2.1 人工输入

人工输入是管理层、项目负责人或运营人员维护的规划事实。

包括：

- 项目主数据 Excel。
- 实际进度录入 Excel。
- 项目主数据页面录入或编辑。
- 项目名称。
- 版权方。
- IP。
- 产品类型。
- 项目状态。
- 年度规划。
- 计划上线日期 / 计划上线月份。
- 上线顺序。
- 项目组。
- 产品研发。
- 产品研发美术。
- 建模负责人。
- 预计款式数。
- 路线。
- 备注。
- 允许范围内的规划调整，例如上线日历拖动项目调整规划月份。

人工输入只能维护规划事实和主数据，不能填写预测上线、风险等级、延期判断、里程碑状态等计算结论。

实际进度录入 Excel 只能写任务事实。导入时必须转成 `ProjectTaskFactEvent`，sourceModule 记为 `manual-excel`，并复用任务事实接收逻辑。

### 2.2 产品组工作指引输入

产品组工作指引只向项目排期提交任务事实事件，不写风险、不写预测、不写排期结果。

统一入口：

```text
POST /api/schedule/task-fact-events
```

第一版联调事件：

- `task_started`
- `task_completed`

项目排期接口可以保留后续扩展事件类型，但产品组第一版只需要发送开始和完成。

任务事实事件只能表达：

- 实际开始日期。
- 实际完成日期。
- 当前任务状态。
- 操作人。
- 操作时间。
- 备注。

产品组工作指引不能提交：

- 预测完成时间。
- 预测上线日期。
- 风险等级。
- 延期结论。
- 里程碑状态。
- 产能结论。

### 2.3 统一排期内核输入

统一排期内核输入是指项目排期触发或执行内核测算后，接收并保存的计算结果。

包括：

- `ScheduleProjectResult`
- `ScheduleTaskResult`
- `TaskCard`
- `Alert`
- 预测上线日期。
- 任务预测完成时间。
- 延期天数。
- 风险等级。
- 当前任务。
- 里程碑状态。
- 风险提醒。

这些数据对项目排期来说是“内核结果输入”，不是项目排期自己主动生成的输出。项目排期负责保存、展示和发布，不负责重新计算。

项目排期业务入口只能调用 `src/lib/schedule-engine/service.ts` 暴露的排期引擎端口服务。`legacy/schedule-engine/*` 和 `src/lib/schedule-engine/adapters.ts` 只是当前默认适配器，不允许页面组件、API 路由或其他模块直接依赖 legacy 计算脚本。

## 3. 输出

项目排期模块没有主动输出。

项目排期不主动写回其他模块，不主动通知其他模块，不生成跨模块事实事件。

原先容易被称为“输出”的看板、日历、任务列表、风险提醒、任务清单和排期结果，在本边界下统一归入“对外可读信息”。其他模块需要这些信息时，由其他模块主动读取项目排期公开的数据契约。

## 4. 读取

读取指项目排期主动从其他模块或共享数据中读取基础数据。

读取的数据只用于展示、组装排期内核输入或辅助用户理解，项目排期不维护这些基础数据。

项目排期可以读取：

- 用户数据：人员、团队、角色、账号。
- 建模排期对外可读信息：款式状态、建模进度、建模通过、送审反馈、产能异常。
- 任务规则。
- 排期规则。
- 里程碑规则。
- 导入批次。
- 历史排期结果。

读取不等于拥有。项目排期可以读取建模状态，但不直接维护建模师分配、外包安排和建模产能。

## 5. 对外可读信息

对外可读信息指其他模块可以读取项目排期维护或发布的数据。

其他模块可以展示这些信息，但不能直接写项目排期状态，也不能自己重新计算排期结论。

项目排期对外可读信息包括：

- 项目主数据。
- 计划上线日期 / 月份。
- 预测上线日期。
- 当前阶段。
- 风险等级。
- 是否延期。
- 延期天数。
- 任务明细。
- 任务状态。
- 任务阻塞状态。
- 阻塞原因。
- 任务计划 / 预测 / 实际完成时间。
- 里程碑状态。
- `ScheduleProjectResult`
- `ScheduleTaskResult`
- `TaskCard`
- `Alert`
- 最新 `scheduleRunId` 对应的排期结果。
- 项目排期 Excel 导出：包含 `项目信息表2026`、`实际进度录入表`、`任务规则v4`，用于人工回传规划和任务事实。

其他模块如果需要排期信息，只能读取这些对外可读信息，不能要求项目排期主动写回它们，也不能绕过项目排期接口直接改任务事实或排期结果。
