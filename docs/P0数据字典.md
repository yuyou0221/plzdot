# P0 数据字典

最后更新：2026-05-27

本文档把《平台数据结构设计草案》落到字段层面，用于后续设计数据库、Excel 导入接口、页面表单和模块输入输出。

当前版本是 P0 草案，不是最终 Prisma schema。后续还需要单独做一份「现有 schema 对照改造清单」。

## 字段规则

字段分为六类：

| 类型 | 说明 |
| --- | --- |
| 主数据 | 项目、版权方、IP、人员、团队、产品类型等相对稳定的数据 |
| 规划输入 | 管理层做规划时维护的数据，例如计划上线月份、项目等级、项目状态 |
| 执行事实 | 产品组、建模组在推进过程中写入的数据，例如完成日期、反馈、阻塞 |
| 计算输出 | 排期内核或产能算法输出的数据，例如预测完成日、风险等级、超载判断 |
| 配置规则 | 任务编号、任务模板、里程碑分组、上线日期分配规则 |
| 历史记录 | 导入批次、字段变化、换人记录、反馈轮次 |

Excel 覆盖规则：

| 规则 | 说明 |
| --- | --- |
| 可合并覆盖 | 普通 Excel 导入可以按项目 / 记录匹配后覆盖 |
| 可补充 | Excel 可以补空值，但不主动覆盖已有值 |
| 仅全量替换 | 只有总经理 / admin 执行全量替换时允许覆盖 |
| 不可覆盖 | 不能被普通 Excel 覆盖，通常是系统 ID、历史记录、计算结果 |
| 只读输出 | 由系统生成，Excel 最多导出查看，不能作为输入 |

权限口径：

| 角色 | 说明 |
| --- | --- |
| 总经理 | 可做高危全量替换和核心规划决策 |
| 产品总监 | 可维护项目规划、项目组分配、部分业务配置 |
| 产品研发 | 主要填写任务执行事实 |
| 产品研发美术 | 主要维护款式清单、原画相关事实、建模验收事实 |
| 建模组长 | 维护建模预计工作日、分配建模资源 |
| 建模师 | 更新个人建模任务进度 |
| 系统 | 生成 ID、计算预测、计算风险、计算产能 |

## Project 项目

项目的唯一身份是系统生成永久 ID。业务项目编号和项目名称都不能作为唯一键。

| 字段名 | 中文名 | 类型 | 必填 | 维护来源 | Excel 规则 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| `id` | 项目系统 ID | string | 是 | 系统 | 不可覆盖 | 项目真正唯一身份 |
| `businessProjectCode` | 业务项目编号 | string | 否 | 总经理 / 产品总监 | 可合并覆盖 | 例如 `26015`，可为空、后补、修改 |
| `name` | 项目名称 | string | 是 | 总经理 / 产品总监 | 可合并覆盖 | 名称允许修改，但不作为唯一键 |
| `status` | 项目状态 | enum | 是 | 总经理 / 产品总监 | 可合并覆盖 | 见项目状态枚举 |
| `primaryLicensorId` | 主版权方 ID | string | 是 | 总经理 / 产品总监 | 可合并覆盖 | 项目至少要有一个版权方 |
| `productTypeId` | 产品类型 ID | string | 否 | 总经理 / 产品总监 | 可合并覆盖 | 影响任务模板、周期、难度、成本 |
| `seriesGeneration` | 系列代数 | string / int | 否 | 总经理 / 产品总监 | 可合并覆盖 | 例如 mini3、2代、4代 |
| `targetYear` | 目标年份 | int | 否 | 总经理 / 产品总监 | 可合并覆盖 | 用于项目简称和规划辅助 |
| `projectLevel` | 项目等级 | enum | 否 | 总经理 / 产品总监 | 可合并覆盖 | 表示项目优质程度 |
| `urgencyLevel` | 紧急程度 | enum | 否 | 总经理 / 产品总监 | 可合并覆盖 | 表示时间压力 |
| `priorityScore` | 综合优先级 | number | 否 | 系统 / 管理层确认 | 只读输出 | 由等级、紧急程度等共同影响 |
| `plannedLaunchMonth` | 计划上线月份 | year-month | 否 | 总经理 / 产品总监 | 可合并覆盖 | 精确到月份，不人工填具体日期 |
| `suggestedLaunchDate` | 建议上线日期 | date | 否 | 系统 | 只读输出 | 系统按当月项目数量计算 |
| `planningCycleId` | 年度规划周期 ID | string | 否 | 系统 / 管理层 | 可合并覆盖 | 春节后第一个月到下个春节前 |
| `projectTeamId` | 项目小组 ID | string | 否 | 产品总监 | 可合并覆盖 | 例如忍者组、迪no组 |
| `productOwnerId` | 产品研发 ID | string | 否 | 产品总监 | 可合并覆盖 | 主要推进项目 |
| `productArtistId` | 产品研发美术 ID | string | 否 | 产品总监 | 可合并覆盖 | 负责原画、建模验收等 |
| `expectedStyleCount` | 预估款式数 | int | 否 | 产品研发美术 / 管理层 | 可合并覆盖 | 立项阶段只是大概数量 |
| `notes` | 项目备注 | text | 否 | 管理层 / 产品组 | 可合并覆盖 | 非结构化补充 |
| `createdAt` | 创建时间 | datetime | 是 | 系统 | 不可覆盖 | 系统记录 |
| `updatedAt` | 更新时间 | datetime | 是 | 系统 | 不可覆盖 | 系统记录 |

项目状态枚举：

| 值 | 说明 |
| --- | --- |
| `项目池中` | 留位项目、备选项目、尚未进入正式规划 |
| `规划中` | 已进入规划，但尚未正式立项 |
| `已立项` | 已正式确定要做 |
| `推进中` | 项目正在执行 |
| `暂停` | 暂停推进 |
| `取消` | 项目取消，后续复活应新建项目 |
| `已完结` | 项目完成 |

影响模块：

- 项目排期
- 上线日历
- 产品组工作指引
- 建模排期
- 财务测算

| `name` | 任务名称 | string | 是 | 管理层 / 系统配置 | 可合并覆盖 | 例如根据效果图建模 |
| `milestoneType` | 里程碑类型 | enum | 是 | 管理层 / 系统配置 | 可合并覆盖 | 原画、建模、红蜡、平面、产前、大货 |

注意：

- 计划开始 / 完成日期不放在事实表里人工维护。
- 计划时间来自排期内核输出。

## Style 款式

款式由产品研发美术录入。

款式继承项目的产品类型和难度，但未来可支持款式级例外。

| 字段名 | 中文名 | 类型 | 必填 | 维护来源 | Excel 规则 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| `id` | 款式 ID | string | 是 | 系统 | 不可覆盖 | 系统永久 ID |
| `projectId` | 项目 ID | string | 是 | 系统 / 导入匹配 | 可合并覆盖 | 所属项目 |
| `styleSequence` | 项目内顺序号 | int | 是 | 产品研发美术 | 可合并覆盖 | 第 1 款、第 2 款，可调整 |
| `name` | 款式名称 | string | 是 | 产品研发美术 | 可合并覆盖 | 款式名称 |
| `artworkFileUrl` | 原画图 | string | 是 | 产品研发美术 | 可合并覆盖 | PNG / JPG |
| `estimatedModelingWorkdays` | 预计建模工作日 | int | 是 | 建模组长 | 可合并覆盖 | 后续系统可给建议 |
| `artworkApprovedAt` | 原画过审日期 | date | 是 | 产品研发美术 / 产品组 | 可合并覆盖 | 原则上过审后才能建模 |
| `modelingStartedAt` | 建模开始日 | date | 是 | 建模排期 / 建模师 | 可合并覆盖 | 特殊提前需要备注 |
| `modelingInternalApprovedAt` | 建模内部通过日期 | date | 是 | 产品研发美术 | 可合并覆盖 | 内部检修满意后 |
| `modelingApprovedAt` | 建模过审日期 | date | 是 | 产品研发美术 / 建模排期 | 可合并覆盖 | 版权方通过 |
| `earlyModelingApprovalNote` | 提前建模审批备注 | text | 否 | 产品研发美术 / 管理层 | 可合并覆盖 | 原画未过审提前建模时必填 |
| `isRequired` | 是否必做 | boolean | 否 | 产品研发美术 | 可合并覆盖 | 后续用于项目完成规则 |
| `status` | 款式状态 | enum | 是 | 产品研发美术 / 系统 | 可合并覆盖 | 启用、取消等 |

款式数量锁定规则：

- 原画和建模期间可以变化。
- 原画完成后变化概率很小，但允许。
- 红蜡完结并进入模具后，不允许再变化。

| 建模排期 Excel | ModelingTask、ModelingAssignmentHistory、ModelingFeedbackRound | 合并补充 | 建模状态和分配 |
| 用户组织 Excel | User、Department、ProjectTeam、UserBusinessRole | 合并补充 / 全量替换 | 人员基础数据 |

全量替换只允许总经理 / admin 执行，并且必须先备份数据库。

## P0 模块只读 / 可写边界

| 模块 | 可写数据 | 只读数据 |
| --- | --- | --- |
| 项目排期 | 管理层规划输入、导入批次、规划调整记录 | 预测结果、风险等级、任务计划结果 |
