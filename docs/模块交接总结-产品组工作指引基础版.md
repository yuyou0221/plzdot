# 模块交接总结-产品组工作指引基础版
最后更新：2026-05-25

## 模块范围

本轮处理「产品组工作指引」基础版和页面入口，不处理财务、知识库完整系统、权限登录、送审 AI、项目排期重构。

## 做了什么

新增 `/product-guide` 产品组工作指引页面，并在侧边栏加入「产品组工作指引」入口。

页面已按最新上下文调整为更简洁的项目组独立页面：

- 项目组切换：每次只展示一个项目组，支持上一项目组、下一项目组和下拉切换。
- 默认项目组：当前没有登录体系，先使用浏览器本地记忆上次查看的项目组；后续接入登录后替换为当前用户所在组。
- 顶部取消数字指标卡，不再直接展示今日需处理、本周需处理、风险数量等焦虑型数据。
- 页面上方压缩为紧凑工具栏，筛选默认收起到「筛选」下拉里，让里程碑 / 本周工作指引更快进入首屏。
- 里程碑看板外框、列宽、表头和项目卡保持项目排期页原尺寸；分项目组后仅月份行高适度收紧，避免空白过多。
- 每个项目组有两个页面：
  - 里程碑：参照项目排期的里程碑看板，按「月份 × 里程碑」矩阵展示，并提供「规划视图 / 压力预测」明确切换入口。
  - 里程碑看板数据源使用项目排期完整 `ProjectCard`，不是工作指引事项列表，因此能看到该项目组所有项目的里程碑项目卡。
- 本周工作指引：分为「本周需完成」「本周在推进」「本周要开始」「风险任务」「版权方反馈」五个模块。
- 本周工作指引任务卡已改为单行任务条，按「项目 / 任务 / DDL / 延期线」列头对齐展示真实内容。
- 本周工作指引五类任务已改为纵向排列，不再四宫格展示。
- 详情卡默认隐藏，只有点击任务或里程碑项目后才显示。
- 保留辅助筛选：搜索、产品研发、产品美术、我的视角、只看风险、只看我负责。
- 点击任务后右侧显示详情：任务说明、提醒原因、建议下一步、相关项目进度、建模进度摘要、风险文案、后续 SOP / 知识库占位。
- 新增项目分析子页面：从工作指引详情或里程碑详情进入，展示单个项目的基础信息、最新测算结论、建模摘要和全部任务状态 / 测算结果。
- 保留基础执行动作：标记完成、更新预计完成日期、标记 / 解除阻塞、录入建模款式。

## 新增 API

```text
PATCH /api/product-guide/tasks/:id
POST /api/product-guide/modeling-tasks
```

`PATCH /api/product-guide/tasks/:id` 支持：

```text
complete：标记任务已完成
expected-finish：更新预计完成日期
submit-review：记录任务已送审
block：标记阻塞
unblock：解除阻塞
```

`POST /api/product-guide/modeling-tasks` 作为旧入口保留，当前口径应桥接到建模排期的款式清单提交契约；提交后款式进入 `待确认`，等待建模侧确认，不应直接生成 `未分配` 款式。

## 业务口径

- 已完成 / 已完结项目不进入当前风险指引。
- 项目级风险会生成当前推进指引。
- 排期任务进入指引的条件：当前任务、近期关键路径任务、阻塞、超 3 天未更新、或近期延期风险。
- 建模待处理进入指引的条件：未分配款式、已送审、等反馈、修改卡住、建模中超 3 天未更新。
- 「延期完成」作为历史结果，不作为当前风险任务进入待处理列表。
- 建议动作使用普通负责人可读文案，不展示脚本状态。
- 产品组工作指引可以写执行事实，但不修改项目计划上线日期、项目路线、项目等级、规划里程碑月份等规划基线。
